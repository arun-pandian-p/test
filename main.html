About Me

Full-Stack Software Engineer based in Coimbatore, Tamil Nadu, India. Focused on building modern web applications using React, Java, Spring Boot, REST APIs, and PostgreSQL.

My engineering trajectory began in the analytical domains of Artificial Intelligence and Data Science. Working with complex statistical algorithms, raw data flows, and machine learning models quickly exposed a fundamental truth: models and analyses are only as impactful as the software architecture supporting them. This insight drove my transition into comprehensive full-stack software development. I wanted to design entire product lifecycles — from responsive React user interfaces down to robust Java backend services, transactional relational schemas in PostgreSQL, and rock-solid API contracts.
